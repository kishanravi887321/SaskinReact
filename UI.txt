🎯 Integration Method:
```javascript
// Initialize pipeline
const pipeline = new InterviewPipelineAPI();

// Start interview
const startInterview = async (config) => {
  const result = await pipeline.startInterview(userId, {
    role: config.role,
    experience: config.experience,
    industry: config.industry
  });

  if (result.status === 'success') {
    // Play welcome question audio
    playAudio(result.question_audio_path);
    // Display question text
    displayQuestion(result.question);
  }
};
```

-------------------------------------

🔌 API Endpoints to Create:

POST /api/interview/start/
- Payload: {user_id, role, experience, industry}
- Response: {session_id, question, audio_path}

POST /api/interview/submit-audio/
- Payload: {session_id, audio_file}
- Response: {transcription, feedback, next_question, audio_paths, status}

GET /api/interview/session/{session_id}/
- Response: {session_info, progress, status}

POST /api/interview/session/{session_id}/cleanup/
- Response: {cleanup_status}

```javascript
// File upload for audio responses
const uploadAudio = async (audioBlob, sessionId) => {
  const formData = new FormData();
  formData.append('audio', audioBlob, 'response.wav');
  formData.append('session_id', sessionId);

  return await fetch('/api/interview/submit-audio/', {
    method: 'POST',
    body: formData
  });
};
```

5. UI/UX WORKFLOW SEQUENCE
--------------------------

🔄 User Journey Flow:

1. Interview Setup Page
   → User selects role, experience, industry
   → Microphone permission & test
   → Click "Start Interview"

2. Welcome Screen
   → Pipeline initializes session
   → First question audio plays automatically
   → Question text displays
   → "Start Recording" button appears

3. Recording Phase
   → User clicks "Start Recording"
   → Recording indicator shows (red dot, timer)
   → Real-time transcription appears
   → User clicks "Stop Recording" or auto-stop after time limit

4. Processing Phase
   → "Processing..." spinner
   → Audio gets sent through VTT → Gemini → TTV pipeline
   → Results return with transcription, feedback, next question

5. Feedback Phase
   → AI feedback audio plays automatically
   → Feedback text displays with score
   → Strengths and improvements show
   → "Continue to Next Question" or "Complete Interview" button

6. Completion Phase
   → Final summary displays
   → Overall score and detailed feedback
   → Download interview report option
   → "Start New Interview" button
